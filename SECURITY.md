# Security Policy

## Supported Versions

Security updates and patches are actively provided for the latest release line of SmartNoteAI:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

The SmartNoteAI project takes the security of our users and their data seriously. If you believe you have discovered a security vulnerability in this application, please report it responsibly.

### How to Report
- **Do not** report security vulnerabilities in public GitHub issues.
- Please report vulnerabilities privately by opening a [GitHub Security Advisory](https://github.com/sgr-m/SmartNoteAI/security/advisories/new) or by contacting the maintainer directly via GitHub profile contact details.
- Please provide as much information as possible, including:
  - Description of the vulnerability and its potential impact.
  - Step-by-step instructions or proof-of-concept to reproduce the issue.
  - The version of SmartNoteAI and Windows environment tested.

### What to Expect
- You will receive an acknowledgment of your report within 48 hours.
- We will work with you to understand and address the issue promptly before public disclosure.
- Security fixes will be released as patch updates in the GitHub Releases section.
